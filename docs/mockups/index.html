Protótipo 1 — UX Design
Foco: Hierarquia, Fluxo & Ergonomia

Principais Decisões

  • Hierarquia clara: Tabuleiro > Teclado > Ações secundárias
  • Mobile-first: Teclado fixo no rodapé, zonas de toque ≥ 44px
  • Fluxo minimizado: Menos cliques, ações frequentes em destaque
  • Feedback imediato: Toasts inline, estados visuais claros
  • Separação de risco: Botão de dica isolado com aviso de custo
  • Ações rápidas: Modos, estatísticas e configurações acessíveis

Destaques

  • Tabuleiro 6×5 funcional
  • Teclado virtual + físico
  • Modal de estatísticas
  • Indicador de tentativas restantes

Protótipo 2 — Acessibilidade (WCAG 2.1 AA)
Foco: Inclusão & Usabilidade Universal

Principais Decisões

  • Não depende só de cor: Símbolos (✓, ~, ✕), bordas e texturas
  • Contraste verificado: Todos os elementos atendem WCAG AA
  • Navegação por teclado: Tab, setas, Enter, Backspace
  • ARIA completo: Grid, live regions, focus trap em modais
  • Reduzir movimento: Respeita prefers-reduced-motion
  • Modo alto contraste: Toggle opcional

Destaques

  • Legenda textual dos estados
  • Anúncios via screen reader
  • Funciona em zoom 200%
  • Roving tabindex no teclado

Protótipo 3 — Design Visual
Foco: Identidade & Polimento

Conceito: "Expedição Noturna"

  • Identidade própria: Radar de expedição, lupa com retícula
  • Tema escuro primário: Azul-noite com brilhos radiais
  • Tema claro: "Caderno de Campo" (papel creme)
  • Tipografia: Georgia (marca) + system-ui (tabuleiro)
  • Paleta semântica: Ciano radar, verde esmeralda, âmbar lanterna

Destaques

  • Flip 3D com transições suaves
  • Sons via Web Audio API
  • Efeitos de vitória/derrota
  • Microanimações polidas
